最終更新：2026-11-23。

## この頁の位置づけ

このサイトが日本の法令のどこに触れうるかと、触れないために決めていることを並べた頁です。
運営者の側の理解を書いたもので、読む人への法的な助言ではありません。
弁護士の確認は受けていません。
引く条文は、運営者の別のリポジトリの見張りが e-Gov 法令 API から取り寄せて記した文を、そのまま写しています（下の「条文」）。法令の文を記憶から書いてはいません。
日本の外の法令は、調べていません。
書体・印・ファビコン・図・配色など、見た目の部品の扱いは、[デザインに関する法的な扱い](design.html)に分けて書いています。

## 前提となる事実

- サイトは静的な頁と、ブラウザの中だけで動く遊び場です。何も集めず、何も売らず、広告も寄付もありません。
- 原典は運営者の文で、遊びの部分は運営者の求めで Claude が書きました。他人の著作物を写していません。
- 特定の人の名を挙げず、実在の人を例にしません。
- 性的な描写を含みません。

## 条ごとの整理

| 法令 | 触れうる道 | このサイトの決め |
| --- | --- | --- |
| 刑法 第230条・第231条 | 人を魔法使いだと言い立てたり、性経験を言いふらしたりすること | 特定の人を挙げない。図鑑の「見分け方」で、身の回りの人に当てはめることは遊びの外だと書く。利用規約で、人を言い立てる使い方を想定していないと示す |
| 刑法 第233条 | 虚偽の風説で人の信用を損なうこと | 人や事業者を挙げない |
| 民法 第709条 | 人の権利や利益を侵すこと | 上の二つと同じ。人の情報を集めない |
| 著作権法 第21条・第23条 | 他人の著作物を写し、送信すること | 原典は運営者の文。遊びの文と図は Claude が新しく書き、ほかの作品を写していない。図は直線・円・多角形だけで新しく描いた。配る書体は、SIL Open Font License 1.1 の英字書体 Inter Tight だけで、許諾の文を添える |
| 景品表示法 第5条 | 商品や役務の取引で、実際より良く見せる表示 | 何も売らず、取引がない。魔法使いの認定のようなものを出さない |
| 消費者契約法 第10条 | 消費者の利益を一方的に害する条項 | 同意の手続きを置かず、利用規約を契約の条項として結ばない。運営者の責任は法令のとおりとし、法令が認める以上に軽くしない。消費者契約に当たるかを定める条（第2条）は引いていない |
| 民法 第548条の2 | 定型約款の合意 | 同意の手続きを置かない。利用規約を合意の内容とする仕組みがない |
| 商標法 第25条 | 他人の登録商標を、同じ商品や役務に使うこと | 登録の有無は調べていないと書き、権利者から知らせがあれば名を変えるか使うのをやめる。出願しないことは、この道を避ける手段ではない |

## 規約の外で、法令に触れうる行い

このサイトの文を使って、実在の人を魔法使いだと言い立てたり、性経験を話題にしてからかったりすることは、上の刑法と民法の条に触れうる行いです。
利用規約は、そうした使い方を想定していないと示しています。
このサイトが、そうした行いを勧めることはありません。
