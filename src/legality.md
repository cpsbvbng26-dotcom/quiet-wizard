# 適法性の説明

最終更新：2026-11-23。

## この頁の位置づけ

このサイトが日本の法令のどこに触れうるかと、触れないために決めていることを並べた頁です。
運営者の側の理解を書いたもので、読む人への法的な助言ではありません。
弁護士の確認は受けていません。
引く条文は、運営者の別のリポジトリの見張りが e-Gov 法令 API から取り寄せて記した文を、そのまま写しています（下の「条文」）。法令の文を記憶から書いてはいません。
日本の外の法令は、調べていません。
書体・印・ファビコン・図・配色など、見た目の部品の扱いは、[デザインに関する法的な扱い](design.html)に分けて書いています。

## 前提となる事実

- サイトは静的な頁と、ブラウザの中だけで動く遊び場です。何も集めず、何も売らず、広告も寄付もありません。
- 原典は運営者の文で、遊びの部分は運営者の求めで Claude が書きました。他人の著作物を写していません。
- 特定の人の名を挙げず、実在の人を例にしません。
- 性的な描写を含みません。
- [みんなの図鑑](entries.html)には、読む人が GitHub の issue で寄せ、運営者が読んで選んだ場面だけを載せます。頁そのものは、何も受け取りません。寄せた場面は、寄せた人の文です。

## 条ごとの整理

| 法令 | 触れうる道 | このサイトの決め |
| --- | --- | --- |
| 刑法 第230条・第231条 | 人を魔法使いだと言い立てたり、性経験を言いふらしたりすること | 特定の人を挙げない。図鑑の「見分け方」で、身の回りの人に当てはめることは遊びの外だと書く。利用規約で、人を言い立てる使い方を想定していないと示す |
| 刑法 第233条 | 虚偽の風説で人の信用を損なうこと | 人や事業者を挙げない |
| 民法 第709条 | 人の権利や利益を侵すこと | 上の二つと同じ。人の情報を集めない |
| 著作権法 第21条・第23条 | 他人の著作物を写し、送信すること | 原典は運営者の文。遊びの文と図は Claude が新しく書き、ほかの作品を写していない。図は直線・円・多角形だけで新しく描いた。配る書体は、SIL Open Font License 1.1 の英字書体 Inter Tight だけで、許諾の文を添える |
| 景品表示法 第5条 | 商品や役務の取引で、実際より良く見せる表示 | 何も売らず、取引がない。魔法使いの認定のようなものを出さない |
| 消費者契約法 第10条 | 消費者の利益を一方的に害する条項 | 読む人には同意の手続きを置かず、利用規約を契約の条項として結ばない。場面を寄せる人が様式で付ける印は、寄せた文の許諾と、決めた三つの直しへの同意と、年齢などの確かめで、運営者はこれを、利用規約を契約の条項とする合意としては扱わない。運営者の責任は法令のとおりとし、法令が認める以上に軽くしない。消費者契約に当たるかを定める条（第2条）は引いていない |
| 民法 第548条の2 | 定型約款の合意 | 読む人には同意の手続きを置かない。利用規約を合意の内容とする仕組みがない。場面を寄せる人の印も、利用規約を合意の内容とするものとしては置いていない |
| 商標法 第25条 | 他人の登録商標を、同じ商品や役務に使うこと | 登録の有無は調べていないと書き、権利者から知らせがあれば名を変えるか使うのをやめる。出願しないことは、この道を避ける手段ではない |

## 参加（みんなの図鑑）の法的な扱い

[みんなの図鑑](entries.html)では、読む人が GitHub の issue の様式で場面を寄せ、運営者が読んで選んだものだけを頁に載せます。
この節は、その参加の形が触れうる法令と、決めていることと、残ることを、危うさごとに並べます。
ここも、運営者の側の理解を書いたもので、弁護士の確認は受けていません。
引く条文は、上の「この頁の位置づけ」に書いた写しにある条だけです（下の「条文」）。
写しに無い法令と条は、名と番号だけを挙げます。
写しに無い法令と条の文は、取り寄せておらず、確かめていません。

| 危うさ | 関わる法令 | このサイトの決め | 残ること |
| --- | --- | --- | --- |
| 第三者の名誉とプライバシー | 刑法 第230条・第231条、民法 第709条。写しに無いもの：民法 第723条。裁判所の判断が認めてきたプライバシーの利益 | 様式の印で、実在の人や誰のことか分かる人を、名指しも描写もしないことを求める。載せる前に運営者が読み、人を指しうる場面は載せない。受付の機械は、敬称や続柄の後の「は魔法使い」、GitHub の名、リンクなど、決めた語の形を拾う。載せた場面は、求めがあれば外す。issue は、運営者が本文を直すか消す | 決めた語の形に当たらない書き方で人を指す文は、機械では拾えない。運営者が読むまでのあいだ、issue には書かれたとおりに残る |
| 読む前から公開される issue | 上と同じ | 様式の初めの欄と場面の欄の説明に、issue が開いたその時から公開されることを書く。運営者は、決めに触れる issue を見つけしだい、求めを待たずに本文を直すか issue を消す。求め方は[求めと連絡](requests.html)にある | issue を開いてから運営者が読むまでの時間は、決められない。GitHub の編集の履歴と、GitHub の外へ写されたものは、運営者には消せないことがある |
| 寄せた文の著作権 | 著作権法 第21条・第23条 | 様式の印で、自分で新しく書いた文で、他人の文や作品を写していないことと、文を CC BY 4.0 で許諾することを求める。著作権は寄せた人に残る。権利者から知らせがあれば、判断の前にその場面を外す | 写したかどうかを、運営者は確かめきれない |
| 著作者人格権 | 著作権法 第19条・第20条 | 運営者が手を入れるのは、寄せた人が様式の印で同意した三つ（長さを詰めること、表記をそろえること、このサイトの決めに合わない語を替えること）に限る。意味の変わる直しは、その issue で尋ね、同意があってからにする。手を入れた場面には、そのことを頁に記す。著作者人格権を行使しないことは求めない。名の表示は、寄せた人の「名の表示」の印のとおりにし、印が無ければ名を出さない | 三つの直しのどれに当たるかの線引きは、運営者の読みによる。寄せた人は、手を入れた場面を外すことを求められる |
| 性を題材にした遊びと、未成年 | 条は挙げない。性的な描写を載せないことと、年齢の印は、このサイトの決めとして置く | 様式の印で、十八歳以上であることを求める。誰の性経験にも触れず、性的な描写もないことを印で求め、受付の機械も決めた語を拾う。性的な描写のある場面は載せない | 年齢は印だけで、確かめる手段は無い |
| 個人情報 | 写しに無いもの：個人情報の保護に関する法律（個人情報保護法）、その第28条（外国にある第三者への提供） | 扱うのは、issue を開いた人の GitHub の名と、issue に書かれたこと。目的は、場面を読み、載せるかを決め、載せ、求めに答えることだけ。名を頁に出すのは、「名の表示」の印があるときだけ。題と本文を Claude（Anthropic、米国）に渡すのは、同意の印があるときだけで、第28条の外国にある第三者への提供として扱う。求めがあれば、載せた場面と名を外す。issue は GitHub（米国）が自分の決まりで持つ（[個人情報の取り扱い](privacy.html)） | この法律の文は写しに無く、条ごとの当てはめは確かめていない |
| 発信する者と、場を出す者の責任 | 写しに無いもの：情報流通プラットフォーム対処法（以前の通称はプロバイダ責任制限法） | issue の場は GitHub が出す。サイトに載せた場面は、運営者が読んで選んで載せたものなので、運営者が自分で載せたものと同じに扱う。この頁は、この法律が運営者の責任を軽くするとは考えない。権利を侵すという知らせは[求めと連絡](requests.html)で受け、判断の前に、その場面を頁から外し、issue の本文を直すか issue を消す | この法律の文は取り寄せておらず、運営者がこの法律のどの立場に当たるか、どの手続きが掛かるかを確かめていない |
| 差別と、人を傷つける書き方 | 刑法 第231条、民法 第709条 | 人をからかう場面、誰かを狙う場面、人を属性で分ける場面は載せない。様式の印で、誰も魔法使いと呼ばないことを求める | 載せない判断は、運営者の読みによる |
| 対価と賞品 | 景品表示法 第5条 | 寄せた人に対価も賞品も出さない。寄せる人から料金を取らない。載せることは賞ではない。何も売らない | なし |

写しに無い法令と条（民法 第723条、個人情報保護法とその第28条、情報流通プラットフォーム対処法）は、名と番号だけを挙げています。条文は取り寄せておらず、確かめていません。

## 規約の外で、法令に触れうる行い

このサイトの文を使って、実在の人を魔法使いだと言い立てたり、性経験を話題にしてからかったりすることは、上の刑法と民法の条に触れうる行いです。
利用規約は、そうした使い方を想定していないと示しています。
このサイトが、そうした行いを勧めることはありません。
