# 利用規約

最終更新：2026-11-24。

## この決まりについて

この頁は、サイト「ステルス・ウィザード」（2026-11-21 までの名は「地味な魔法使い」）とそのリポジトリの使い方の決まりです。
サイトには申し込みも登録もなく、読む人がこの決まりに同意する手続きもありません。
そのため、この決まりは、読む人と結ぶ約束ではなく、サイトが何をし、何をしないか、どんな使い方を想定していないかを示すものです。
[みんなの図鑑](entries.html)に場面を寄せる人は、寄せる様式で印を付けます。その印は、寄せた文の許諾と、決めた三つの直しへの同意と、年齢などの確かめです（下の「寄せた場面」）。

## このサイトとは何か

都市伝説を題材にした、娯楽のための読み物と遊びです。
科学の法則・医学・心理学・性に関わる助言のどれでもありません。
誰の性経験も評価せず、特定の人を魔法使いと呼びません。
性的な描写を含みません。
内輪ノリであり、気分を害する方がいる可能性があります。ご注意ください。
選民思想ではなく、魔法使いを、ほかの人より優れた者とも、選ばれた者ともしません。
運営者は、魔法使いの代表ではありません。

## 費用

このサイトは、誰からも料金を取りません。
何も売らず、寄付を受けず、広告を出しません。
魔法使いの認定・称号・証明書のようなものを出しません。
そうしたものを有料で出すと称する者がいても、このサイトとは関係がありません。

## 想定していない使い方

このサイトは、次の使い方を想定していません。


- このサイトの文や図を使って、実在の人を魔法使いだと言い立てること。
- このサイトの文や図を、人の性経験を詮索したり、からかったり、責めたりする材料にすること。
- このサイトの文を、科学・医学・心理学の根拠として示すこと。
- このサイトや運営者が認めた、と偽って何かを示すこと。
- サイトやリポジトリの動きを妨げること。

## 文と図の使い方

文（原典を含む）と図は、CC BY 4.0 で使えます。コードは MIT です。
使うときは、ライセンスが求める表示をします。
上の「想定していない使い方」は、ライセンスの条件を足すものではありません。このうち、人を言い立てたり傷つけたりする使い方は、法令に触れうる行いです（[適法性の説明](legality.html)）。

## 寄せた場面

[みんなの図鑑](entries.html)に場面を寄せる人は、寄せる様式（GitHub の issue）の確かめの欄で、次の八つに印を付けます。

- 十八歳以上であること。
- 自分で新しく書いた文で、他人の文や作品を写していないこと。
- 実在の人や、誰のことか分かる人を、名指しも描写もしていないこと。
- 誰の性経験にも触れず、性的な描写もないこと。
- 自分やほかの誰かを、魔法使いだと言っていないこと。
- 遊びの文で、科学でも助言でもないこと。
- 文を CC BY 4.0 で許諾し、頁では名を出さないことを選んで、名の表示を求めないこと。
- 載せるときに、運営者が三つに限って手を入れること。長さを詰めること、表記（字、句読点、かなと漢字）をそろえること、このサイトの決めに合わない語を替えることです。

issue は、開いたその時から GitHub で公開されます。運営者が読む前から、誰でも読めます。開いた人の GitHub の名も、一緒に出ます。
寄せた文の著作権は、寄せた人に残ります。運営者と読む人は、CC BY 4.0 の条件で使います。
運営者は、著作者人格権を行使しないことを求めません。手を入れるのは、印で同意を得た三つの直しだけです。
意味の変わる直しは、その issue で尋ね、寄せた人の同意があってからにします。手を入れた場面には、そのことを頁に記します。
頁に載せる場面には、寄せた人の名を出しません。どの場面も名無しで載せ、issue の番号も頁に出しません。
issue そのものは、GitHub の決まりで、開いた人の GitHub の名とともに公開されます。このサイトは、それを変えられません。
寄せは、一つの GitHub のアカウントにつき、生涯で 3 件までです。4 件目からは受けません。
数えるのは、同じアカウントがこのリポジトリで前に開いた、ラベル entry の付いた issue のすべてで、載ったか、選ばれなかったか、閉じたか、取り下げたかを問いません。
運営者が消した issue は、GitHub の一覧に出ないので、数えられません。
一つの法則に場面が 5 件載ったら、その法則の寄せは受けません。図鑑の全体は、多くて 50 件です。
受けない寄せには、受付の機械が、受けないことと、当たった上限をコメントで知らせます。issue は閉じません。
この三つ（名を出さないこと、アカウントごとの上限、法則ごとの上限）は、2026-12-08 から効きます（下の「予定している変更」）。
運営者は、寄せた場面を載せないことがあります。理由を書かないこともあります。
人をからかう場面、誰かを狙う場面、人を属性で分ける場面は、載せません。
載せた場面は、運営者の判断で外すことがあります。寄せた人や場面に関わる人から求めがあれば、すぐに外します。issue の本文を直すことや issue を消すことも、求められます（[求めと連絡](requests.html)）。
寄せた人に対価も賞品も出さず、寄せた人から料金も取りません。載せることは、賞ではありません。
場面を載せても、その場面が法則の正しさを示すことにはなりません。

## 予定している変更

[みんなの図鑑](entries.html)に寄せる人にとって不利になりうる変更を、2026-11-24 にこの頁で示しました。
効力の生じる日は、2026-12-08（日本時間）です。
変えるのは、次の三つです。

- 頁に載せる場面には、寄せた人の名を出さないこと。様式の「名の表示」の欄を外し、許諾の印を、頁で名を出さないことを選ぶ印にしました。
- 寄せは、一つの GitHub のアカウントにつき、生涯で 3 件までとすること。
- 一つの法則に場面が 5 件載ったら、その法則の寄せを受けないこと。

2026-12-08 より前に開いた issue には、二つの上限を当てません。
様式の「名の表示」の欄は、2026-11-24 に外しました。その日までに、みんなの図鑑に寄せた issue はありませんでした。
示した日から効力の生じる日までは、14 日です。この決まりには日数の定めが無く、寄せている途中の人が新しい決まりを読めるように、二週間を置きました。

## 保証しないこと

文と遊び場は、あるがままで置いています。
誤りがないこと、いつも見られることは約束しません。
運営者は、法令が定めるところに従って責任を負います。この決まりは、法令が認める以上に運営者の責任を軽くしません。

## 変更と終了

この決まりとほかの頁は、変わることがあります。
上の案内と下の欄からつなぐ頁には、どれも最終更新の日を書き、その頁の本文を最後に変えた日を示します。上の帯、上下の欄、頁の頭の見えない情報の変更は、その日に数えません。
前の版は、公開のリポジトリの履歴に残ります。最終更新の日の横から、その頁の変更の記録を開けます。
読む人に不利になる変更は、変える中身と効力の生じる日を、その日より前にこの頁で示します。
サイトを閉じるときは、閉じる日を、その日より前にトップの頁で示します。リポジトリは消しません。

## 準拠法と紛争

この決まりは日本法に準拠します。
紛争は、話し合いによる解決を優先します。
話し合いで解決しない紛争は、法令の定める裁判所が管轄します。
この決まりのどの定めも、法令が制限を認めない権利を制限しません。
