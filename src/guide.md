# ステルス・ウィザード図鑑

> これは遊びです。ここに書くのは、原典の十の法則を、暮らしの場面に当てはめた想像です。観察や調査に基づくものではなく、科学の主張でもありません。

## 姿

- **杖**：持っていません。代わりに、折りたたみの傘を持っています。
- **帽子**：かぶっていません。天気に合わせて、傘を選びます。
- **ローブ**：紺か灰色の上着です。長く着られるものを選びます。
- **使い魔**：いません。観葉植物が一鉢あります。
- **魔法瓶**：持っています。名前だけが魔法です。

## 呪文

ステルス・ウィザードの呪文は、短く、効き目が見えません。

| 呪文 | 起きること |
| --- | --- |
| 確認します | 話が一度止まり、誤りが一つ減る |
| お先に失礼します | 本人が帰る。それ以上は何も起きない |
| 大丈夫です | 大丈夫になる。なるまで時間がかかることがある |
| 念のため | 予備が一つ増える |

## 十の法則の、地味な現れ

| 法則 | 地味な現れ |
| --- | --- |
| 第一法則 成立 | 三十歳の誕生日に、何も起きません。何も起きないことが、成立の印です。 |
| 第二法則 多面 | 会議では聞き役の面を向け、友人の前では話し役の面を向けます。どちらも同じ要素です。 |
| 第三法則 保存 | 言えなかった一言は、捨てられずに、引き出しの奥で静かに増えます。 |
| 第四法則 反転 | 溜まった悔しさが、ある日、人の悔しさに気づく力として顕れます。 |
| 第五法則 目安 | 二十七歳で切り替わる者もいます。年齢を数えても、分かりません。 |
| 第六法則 還元 | 成果は、誰かの「なんとなく助かった」に溶けます。本人にも見えないことがあります。 |
| 第七法則 共通 | 成った者どうしは、互いに気づきません。気づいても、言いません。 |
| 第八法則 泥沼 | 布団に入ってから、脳がもう一周します。 |
| 第九法則 秘匿 | ここに具体は書きません。第九法則があるからです。 |
| 第十法則 長命 | 長く生きます。だから、膝と腰を大事にします。 |

## 持ち物

- 予備の充電器
- 付箋
- 小銭入れの中の、使い道の分からない鍵
- 誰にも見せていない帳面

## 見分け方

見分け方はありません。
第六法則のとおり、成果は外から見えず、第七法則のとおり、成った者どうしも言いません。
この図鑑を手がかりに、身の回りの誰かを魔法使いだと決めることは、この遊びの外のことです。
