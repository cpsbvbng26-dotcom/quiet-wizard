# みんなの図鑑

> これは遊びです。ここに並ぶのは、読む人が GitHub の issue で寄せた、十の法則の地味な現れの場面です。観察や調査に基づくものではなく、科学の主張でもありません。

[図鑑](guide.html)の「十の法則の、地味な現れ」と同じ種類の場面を、読む人が寄せる頁です。
寄せる場面は、作り話か、誰にでもありそうな場面です。
載るのは、運営者が読んで選んだ場面だけです。
場面の文は、寄せた人が書いたものです。Claude は、寄せられた場面を書きません。

## 参加の形

参加は、場面を寄せることだけです。
寄せる人が、自分を遊びの参加者や魔法使いとして名を連ねる仕組みは、作っていません。
名を連ねる一覧は、実在の GitHub の利用者を、魔法使いとして並べることになります。
それは、特定の人を魔法使いと呼ばないこと、誰の性経験も評価しないことという、このサイトの決めに触れます。

## 寄せ方

1. GitHub のアカウントで、[寄せる様式](https://github.com/cpsbvbng26-dotcom/quiet-wizard/issues/new?template=entry.yml)を開きます。様式は GitHub の issue です。
2. 法則を一つ選び、短い題と、一つか二つの文の場面を書きます。日本語は 10 字から 200 字まで、英語は 20 文字から 600 文字までです。
3. 確かめの欄の八つの印を付けます。十八歳以上であること、自分で書いた文であること、実在の人を書かないこと、性経験に触れないこと、誰も魔法使いと呼ばないこと、遊びの文であること、CC BY 4.0 の許諾、決めた三つの直しへの同意です。
4. 言語モデルに渡ることへの同意は、任意です。

issue は、開いたその時から GitHub で公開されます。運営者が読む前から、誰でも読めます。開いた人の GitHub の名も、一緒に出ます。
受付の機械（GitHub Actions）は、欄と印がそろっているかを確かめ、ラベルと決まった文のコメントを一つ付けます。
受付の機械は、何も載せず、issue を閉じず、鍵も掛けません。
載せるかどうかは、運営者が読んで決めます。理由を書かずに載せないこともあります。

## 名を出さないこと

この頁に載せる場面には、寄せた人の名を出しません。どの場面も、名無しで載せます。
寄せた issue の番号も、頁には出しません。
issue そのものは、GitHub の決まりで、開いた人の GitHub の名とともに公開されます。これは、このサイトでは変えられません。
許諾の印は、頁で名を出さないことを選び、名の表示を求めないという印です。

## 寄せの数

寄せは、一つの GitHub のアカウントにつき、生涯で 3 件までです。
数えるのは、同じアカウントがこのリポジトリで前に開いた、ラベル entry の付いた issue のすべてで、載ったか、選ばれなかったか、閉じたか、取り下げたかを問いません。
一つの法則に場面が 5 件載ったら、その法則の寄せは受けません。図鑑の全体は、多くて 50 件（十の法則に 5 件ずつ）です。
4 件目の寄せと、5 件載った法則への寄せには、受付の機械が、受けないことをコメントで知らせます。issue は閉じません。
この二つは、2026-12-08 から開いた issue に当てます。決まりは[利用規約](terms.html)の「寄せた場面」と「予定している変更」にあります。

この頁そのものは、何も受け取りません。書き込む欄もありません。
寄せた場面の決まりは[利用規約](terms.html)の「寄せた場面」に、扱う情報は[個人情報の取り扱い](privacy.html)の「みんなの図鑑に寄せた場面」に、法令との関わりは[適法性の説明](legality.html)の「参加（みんなの図鑑）の法的な扱い」にあります。
載せた場面を外すこと、issue を直すか消すことは、[求めと連絡](requests.html)の手順で求められます。
