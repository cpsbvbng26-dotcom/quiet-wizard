# 遊び場：魔法使いに見えている世界

> これは遊びです。ここで動くのは、原典の定義と法則を絵と数の遊びにしたものです。何も測らず、何も占わず、何も記録しません。

魔法使いに見えている世界は、たぶんこんな感じです。
外から見ると、傘を持った人が立っているだけです。
けれど本人の目には、面が回り、負が溜まり、ある日その逆が光り、出した成果は人の関係の中へ溶けていきます。
下の五つの図で順に見てから、遊び場で動かしてみてください。

## 図で見る

### 1. 要素は正多面体で、時と場合で向ける面が変わる

![図1 要素と、時と場合で向ける面（遊び）](fig:fig-faces)

人を作る要素は、さいころのような正多面体です（定義五）。
同じ要素でも、場面が変われば、外へ向ける面が変わります（第二法則）。
面そのものに負と正の別はなく、場面が決めます（定義六）。

### 2. 負は消えずに溜まる

![図2 負の蓄積は減らない（遊び）](fig:fig-stock)

負の面を向けるたびに、瓶に一つ溜まります。
瓶は空になりません（第三法則）。
どこまで溜まると次に進むかは、人によって違います。

### 3. 切り替わり：負の逆が、正として光る

![図3 切り替わり：負の面の逆が正として顕れる（遊び）](fig:fig-switch)

溜まりきると、負の面はそのままに、その向かいの面が正として光り始めます（第四法則）。
三十歳はその目安にすぎず、もっと早いこともあります（第五法則）。遊び場では、遅いこともあるように作っています。
正四面体だけは向かいに面がないので、向かいの頂点が光ります（[原理](strict.html)の[定理六](strict.html#prop-6)）。

### 4. 成果は、出た瞬間に人の関係へ溶ける

![図4 成果は人の関係へ還元され、外からは見えない（遊び）](fig:fig-return)

魔法使いが出した成果は、まわりの人との関係の中へ、何事もなかったように溶けます（第六法則）。
外にいる者には、何も見えません。

### 5. 二つの目

![図5 魔法使いの目と外の目（遊び）](fig:fig-two-views)

左が、魔法使いに見えている世界です。右が、外から見える世界です。
同じ人を見ています。

## 遊んでみる：関係の上で働く法則

原典の法則は、人と人との関係の上で働きます。
下の遊び場では、8 人と、そのあいだの関係の線だけを描きます。
人には、名前も年齢も性別も、どんな属性も付けていません。見るのは、関係の移り変わりだけです。

1. **場面を変える**：魔法使いが、それぞれの人へ向ける面（負か正か）が選び直されます。
2. **一日を過ごす**：負の面を向けた人の数だけ、負が溜まります。
3. **切り替わりを見る**：蓄積が閾に届くと、負を向けていた相手との線の逆が、正として光ります。そのあとは、一日ごとに成果が生まれ、相手と、その隣の人との関係が太くなります。隣の人は、魔法使いでない人から選びます。
4. **自動で過ごす**：日が自動で進み、ときどき場面も変わります。
5. **二つの目を見比べる**：外の目にも、関係の線が太くなるのは見えます。けれど、点はみな同じに描かれ、太くなった線の一本からは、誰のおかげかは分かりません。

魔法使い自身の線は、自分の成果では太りません（[原理](strict.html)の[定理二十三](strict.html#prop-23)）。
外の目で長く見ていると、細いままの線に気づくかもしれません。
それでも、太くなった線の一本からは、その源は決まりません（[定理十八](strict.html#prop-18)）。

## 法則と、遊び場での働き

| 法則 | 遊び場での働き |
| --- | --- |
| 第二法則 多面 | 「場面を変える」で、同じ人へ向ける面が負にも正にも変わる |
| 第三法則 保存 | 蓄積は、一日ごとに増えるだけで、減らない |
| 第四法則 反転 | 閾に届くと、負を向けていた相手との線が金色に光る |
| 第五法則 目安 | 閾は蓄積の数で、歳ではない。開くたびに 18 から 36 のあいだで決まる。三十歳の目安を三十に見立て、それより小さい閾なら早め、大きい閾なら遅めの切り替わりになる |
| 第六法則 還元 | 成果は、相手と、その隣の人との関係を太くする。魔法使い自身の線は太らず、見える成果は 0 のまま |
| 第七法則 共通 | 外の目では、魔法使いもほかの 7 人と同じ点で描く。誰が成った者でも、同じことが起きる |
| 第八法則 泥沼 | 切り替わったあとに「止める」を押しても、止まるのは画面だけ |
| 第九法則 秘匿 | 成果の中身は、どこにも書かない。線が太くなることしか見せない |
| 第十法則 長命 | 日は、止めない限り進み続ける |

## 遊び方の決まり

- 人に属性を付けません。だれを表すものでもありません。
- この遊び場は、ブラウザの中だけで動きます。押したことは、どこにも送らず、残しません。頁を閉じれば、蓄積も消えます。原典の第三法則とは違いますが、それは遊びの側の都合です。
- 動きを減らす設定のブラウザでは、光る動きを省きます。
