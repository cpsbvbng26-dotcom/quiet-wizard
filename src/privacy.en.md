# Privacy Policy

Last updated: 2026-11-23.

## Who handles information

The operator of this site and its repository.

## What the site collects

The site collects nothing.
There are no input fields, cookies, access analytics, advertising tags, or anything loaded from outside servers.
What is pressed in the playground is counted only inside the browser, sent nowhere, and cleared when the page closes.
It asks readers nothing about themselves: not sexual experience, not age, not name.

## Search-side statistics

The head of every page carries a Google Search Console ownership token (the `google-site-verification` meta tag).
The token shows Google that the operator owns this site.
The pages send nothing to Google with this token. The reader's browser does not request anything from Google's servers either.
What the operator can see in Search Console is statistics collected on the Google Search side, such as how often this site appeared in search results and how often it was clicked.
Google produces those statistics under its own rules; this site did not collect them.

## Hosting provider

Vercel (United States) serves the site.
To deliver the pages, Vercel handles the requests it receives (including IP addresses) under its own rules. The operator does not obtain or use those records.

## Issues and private contact

Error reports and requests are received as issues on GitHub (United States). Issues are public, and GitHub handles them under its own rules.
Personal information written in an issue is removed by the operator as soon as it is found; if it cannot be removed, the issue is deleted. Copies left in GitHub's edit history may be beyond the operator's reach.
Private correspondence is used only to reply, and is passed to no one else.
For people without a GitHub account, or who do not make their contact details public, there is currently no private way to get in touch.

## Requests

Anyone who finds an entry about themselves can ask, by the steps in [requests and contact](requests.en.html), for it to be removed or corrected. There is no fee.
It is removed from the current version of the site and the repository. Copies left in the history of the public repository are also removed as far as possible on request.

## Changes to this page

When this page changes, the last-updated date is revised. Earlier versions remain in the repository history.
