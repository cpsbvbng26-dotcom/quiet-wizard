# ステルス・ウィザード

> これは遊びです。
> これは運営者の学術的な活動とは別の、エンターテインメントの枠です。科学ではありません。
> 「三十歳まで童貞なら魔法使いになる」という都市伝説を題材にした、娯楽のためのサイトです。
> ここに書く「法則」は、科学の法則ではありません。医学や心理学の主張でもなく、誰の性経験も評価しません。
> 特定の人を魔法使いと呼ぶものでもありません。

サイト：<https://quiet-wizard.vercel.app/>

元になったのは、運営者が直観から書いた一枚の文「三十歳魔法使い都市伝説について」です。
その文は「本稿は論文とは別のものであり、著者の主体的な直観によるものである」と始まります。
このサイトは、その文から借りた魔法使いの像を、ゲームのクラス「ステルス・ウィザード」に見立てて、遊びとして掘り下げたものです。
ここで言うクラスは、ゲームの職業のたとえです。人を分ける区分ではなく、誰かを当てはめるものでもありません。
2026-11-21 までの名は「地味な魔法使い」です。リポジトリと所在の名（quiet-wizard）は変えていません。

## 頁

| 頁 | 元 | 中身 |
| --- | --- | --- |
| はじめに | `src/index.md` | 断りと、クラス表 |
| 原典 | `src/canon.md` | 元の文。定義九つと法則十を、手を入れずに写す |
| 原理 | `src/strict.md`、`verification/models.js` | 第一巻は、原典の定義と法則を骨に、古典の数学書の形（定義・要請・法則・定理と証明・注解）で組み直した版。第二巻は、法則を一階の述語論理の式に移し、無矛盾・独立・識別の不能・反証の条件・逆の存在・負正の相の数を証す。模型と数は機械で確かめる。Claude が書いたもので、原典ではない |
| 図鑑 | `src/guide.md` | 十の法則が、暮らしの中でどう地味に現れるか |
| 遊び場 | `src/play.md` と `assets/play.js` | 正多面体の面を返し、負を溜め、切り替わりを待つ遊び |
| 問い | `src/faq.md` | 科学なのか、誰が魔法使いなのか |
| 断りと開示 | `src/about.md` | この頁が何でないか、誰が何を書いたか、ライセンス |
| 利用規約・個人情報・求めと連絡・適法性の説明 | `src/terms.md` ほか | 決まりと、法令との関わり。条文は `verification/statutes-texts.json` の写しから組む |

## 作り方

```
node build.js
node verification/check.js
```

`site/` は生成物です。`src/` と `assets/` を直して作り直します。
頁は、ほかのサーバーへ何も要求しません。cookie も、アクセスの解析も、入力を受け取る仕組みもありません。
配信は Vercel で、`site/` を根にしています。
