issue と非公開のやりとり

誤りの知らせや求めは、GitHub（米国）の issue で受けます。issue は公開され、GitHub が自分の決まりで扱います。
issue に書かれた個人の情報は、運営者が見つけしだい外し、外せないときは issue を消します。GitHub の編集の履歴に残る分は、運営者には消せないことがあります。
非公開でやりとりした連絡は、答えるためにだけ使い、ほかへ渡しません。
GitHub のアカウントを持たない人や、連絡先を公開しない人が、非公開で知らせる道は、いまはありません。

サイトとリポジトリのいまの版からは外します。公開のリポジトリの履歴に残る分も、求めがあれば、できる限り消します。
