取り扱う者

このサイトとリポジトリの運営者です。

サイトが集めるもの

サイトは、何も集めません。
書き込む欄、cookie、アクセスの解析、広告のタグ、外のサーバーから読むものはありません。
遊び場で押したことは、ブラウザの中だけで数え、どこにも送らず、頁を閉じれば消えます。
性経験・年齢・名前など、読む人についての何も尋ねません。
みんなの図鑑への場面は、頁ではなく、GitHub の issue の様式で寄せます（下の「みんなの図鑑に寄せた場面」）。

検索の側の集計

どの頁の頭にも、Google Search Console の所有の確認の値（google-site-verification の meta）を置いています。
この値は、運営者がこのサイトの持ち主だと Google に示すためのものです。
頁は、この値で Google へ何も送りません。読む人のブラウザが、Google のサーバーへ何かを要求することもありません。
運営者が Search Console で見られるのは、Google 検索の側で集められた集計です。検索の結果にこのサイトが出た回数や、押された回数などです。
その集計は Google が自分の決まりで作るもので、このサイトが集めたものではありません。

配信する事業者

サイトは Vercel（米国）が配信します。
Vercel は、頁を届けるために、届いた要求（IP アドレスを含む）を自分の決まりで扱います。運営者は、その記録を取り寄せず、使いません。

issue と非公開のやりとり

誤りの知らせや求めは、GitHub（米国）の issue で受けます。issue は公開され、GitHub が自分の決まりで扱います。
issue に書かれた個人の情報は、運営者が見つけしだい外し、外せないときは issue を消します。GitHub の編集の履歴に残る分は、運営者には消せないことがあります。
非公開でやりとりした連絡は、答えるためにだけ使い、ほかへ渡しません。
GitHub のアカウントを持たない人や、連絡先を公開しない人が、非公開で知らせる道は、いまはありません。

みんなの図鑑に寄せた場面

みんなの図鑑の様式は、GitHub（米国）の issue です。
issue は、開いたその時から GitHub で公開されます。運営者が読む前から、誰でも読めます。開いた人の GitHub の名も、一緒に出ます。
扱うのは、issue を開いた人の GitHub の名と、issue に書かれたこと（法則、題、場面、言葉、印）です。
様式は、性経験や本名など、寄せる人についてのことを尋ねません。年齢は、十八歳以上かどうかの印だけです。
使う目的は、場面を読むこと、載せるかを決めること、載せること、求めに答えることだけです。
受付の機械（GitHub Actions）は、GitHub の中で本文の欄と印を確かめ、ラベルと決まった文のコメントを付けます。本文をほかへ送らず、記録にも書きません。
載せると決めた場面は、題、文、言葉、法則の番号、issue の番号、載せた日、手を入れたか、名の表示の印を、リポジトリの data/entries.json に記し、頁に出します。
issue の番号は、名を出す場面でだけ、名から issue へのつなぎとして頁に出ます。
GitHub の名は、様式で「名の表示」に印を付けたときだけ、頁と data/entries.json に書きます。
issue は、GitHub が自分の決まりで持ちます。
載せた場面と名は、求めがあれば、すぐに頁と data/entries.json のいまの版から外します。issue の本文を直す求めと、issue を消す求めにも応じます。

言語モデルに渡すこと

運営者は、このリポジトリの手入れを、言語モデル Claude の手を借りて行います。Claude は、Anthropic（米国の会社）の言語モデルです。
運営者のほかの人が開いた issue の題と本文は、書いた人がその issue の中で同意したときだけ、Claude に渡します。
みんなの図鑑の様式では、「言語モデルに渡ること」の欄の印が、その同意です。印は任意です。
運営者は、これを個人情報保護法第 28 条の外国にある第三者への提供として扱います。この法律の文は、このリポジトリの条文の写しに無く、ここでは引きません。
米国の制度について、運営者は、個人情報保護委員会の米国の制度についての情報に拠ります。
委員会は、連邦について「包括的な法令は存在しない。」としています。
米国は APEC の CBPR システムに加わっており、委員会はその日を「2012年7月25日参加」と示しています。
Anthropic は、プライバシーポリシーで、「appropriate technical and organizational security measures designed to protect personal data from loss, misuse, and unauthorized access, disclosure, alteration, or destruction」を講じていると述べています。
この二つの頁の句は、運営者の別のリポジトリが 2026-11-12 に取り寄せて記した文から写しました。この作業の環境からは、二つの頁を読み直していません。
Anthropic が受け取った題と本文をどれだけ保ち、どう使うかは、運営者のアカウントの設定と Anthropic の規約によります。その設定は、この頁では確かめていません。
印の無い issue は、運営者が自分で読みます。コメントは、印があっても渡しません。
同意は、その issue で、いつでも撤回できます。撤回のあとは、その issue を言語モデルに渡しません。

求め

自分についての記載を見つけたときは、求めと連絡の手順で、消すことや直すことを求められます。費用はかかりません。
サイトとリポジトリのいまの版からは外します。公開のリポジトリの履歴に残る分も、求めがあれば、できる限り消します。
