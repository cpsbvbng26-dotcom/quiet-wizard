Requests and Contact

求めと連絡

This page is an English version of a Japanese page. If the two differ, the Japanese page governs.

Last updated: 2026-11-24 (change history).

What is received

  • Reports of errors in the text.
  • Requests to remove or correct an entry about oneself.
  • Notices from rights holders that a name, figure, or text infringes their rights.
  • Requests to remove a scene added to the Field Guide by Visitors, or to edit the body of the issue or delete the issue.
  • Reports of security problems.

None of these costs anything. They are received from people in any country.

How to make a request

Open an issue in the repository.
Issues are public. It is possible to leave out personal information and the details of a security problem, and write only "requesting private contact".
In that case, if the person has made contact details public on their GitHub profile, the operator replies privately at that address.
If they have not, the operator replies in the issue without going into the details.

After a request

  • When there is a request about an entry concerning a person or about personal information, that entry is removed from the current version before any decision is made. Copies left in the repository history are also removed as far as possible.
  • The operator aims to reply within 7 days.
  • Corrections remain in the repository history.

Scenes in the Field Guide by Visitors

  • The sender can ask for an added scene to be removed, or for the body of the issue to be edited or the issue deleted, by writing in the scene's issue or by opening a new issue. No reason is needed.
  • Anyone who thinks a scene is about them, or that it infringes their rights, can ask in the same way.
  • On a request, the scene is removed promptly from the current version of the page and of data/entries.json, before any decision.
  • Scenes on the page are shown without the sender's name. The name shown with an issue comes from GitHub's rules, and hiding it means deleting the issue.
  • Requests to edit the body of an issue, and to delete an issue, are also met. GitHub's edit history, and copies made outside GitHub, may be beyond the operator's reach.
  • When the operator finds personal information, or anything against the rules, written in an issue, the body is edited or the issue deleted without waiting for a request.

Language models

The operator maintains this repository with the help of a language model (Claude).
The title and text of an issue opened by anyone other than the operator are passed to the language model only when the writer consents within that issue. Without consent, the operator reads it in person. On the form of the Field Guide by Visitors, the box under "Use of a language model" is that consent.
Comments are not passed to the language model.
