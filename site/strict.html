原理：魔法使いの定義と法則

Principia Magi Occulti

これは遊びです。原典の定義九つと法則十を骨にして、古典の数学書の形で組み直した版です。

「厳密」なのは言葉の運びのことで、中身が科学として正しいという意味ではありません。何も測っておらず、確かめてもいません。

この版は、運営者の求めで Claude が書いたものです。原典ではありません。原典の文は、原典の頁に手を入れずに置いてあります。

第一巻は、原典にある定義九つと法則十に、一つずつ対応します。
定義十と、要請二つは、この版で補ったものです。
第二巻は、第一巻の定義と法則を一階の述語論理の式に移し、法則の体系そのものについての定理を証します。
原典にある項には、この版の文を文語で掲げ、その下に原典の文を「原文」として、手を入れずに添えます。
並びは、ニュートン『自然哲学の数学的原理』の「定義」「公理、すなわち運動の法則」と、ユークリッド『原論』の定理と証明に倣いました。

第一巻　定義LIBER I · DEFINITIONES

定義一　魔法使ひ　魔法使ひとは、自らの負と正とを併せ用ゐて能動し、成果を出だす者を謂ふ。その負と正とは、同じ要素の、時を異にする面なるも妨げず。
原文自らの負と正の両方を用いて能動し、成果を出す者をいう。

定義二　童貞　童貞とは、性経験なき者を謂ふ。いづれの時までかは、用ゐる所にて定む。この語は事実を指すのみにして、人の値を指さず。
原文性経験のない者をいう。

定義三　能動　能動とは、人の為す凡ての行ひを謂ふ。発信・記録・働きかけは、その一部に過ぎず。
原文全ての能動をいう。発信、記録、働きかけに限らない。

定義四　成果　成果とは、能動より生ずるものを謂ふ。その形は、時と場合とに由りて定まる。
原文能動によって生じるものをいう。その形は時と場合によって定まる。

定義五　要素　要素とは、人を成すものを謂ふ。凡そ要素は、五つの正多面体のいづれかの形を具ふ。
原文ある者を構成するものをいう。要素は正多面体である。

定義六　負と正　負と正とは、要素が時と場合とに応じて向くる面の相を謂ふ。要素それ自らに負と正との別なし。面の負正もまた、時と場合とを得て始めて定まる。
原文要素が時と場合によって向ける面をいう。要素そのものに負と正の別はない。

定義七　蓄積　蓄積とは、負の消えずして積もり行くことを謂ふ。その量は、負を向けたる度の数を以て量る。
原文負が消えずに溜まっていくことをいう。

定義八　切り替はり　切り替はりとは、積もれる負が、その面の逆を正として顕し始むることを謂ふ。始めて顕るる時を、切り替はりの時と名づく。
原文蓄積した負が、逆の面を正として顕し始めることをいう。

定義九　三十歳　三十歳とは、切り替はりの目安を謂ふ。目安は時を定めず。
原文切り替わりの目安をいう。

定義十　逆　面の逆とは、多面体の中心について、その面と点対称の位に在る面を謂ふ。正四面体にはかかる面なきが故に、その面に向かひ合ふ頂点を以て逆と為す。この頂点もまた、面に準じて負と正とを帯ぶ。
原文なし（この版にて補ふ）

要請POSTULATA

要請一　時　時は前へのみ進む。過ぎたる出来事は、取り消さるることなし。

要請二　値　人の値は、魔法使ひたると否と、童貞たると否とに由らず。

公理、すなはち法則AXIOMATA, SIVE LEGES

第一法則　成立LEX I · CONSTITUTIO　三十歳に至るまで童貞なる者は、いつか必ず魔法使ひと成る。その時の、三十歳の前なるも後なるも妨げず。
原文三十歳まで童貞であれば、魔法使いになる。

第二法則　多面LEX II · MULTIPLICITAS　要素は定まらず。時と場合とに由りて、向くる面を変ふ。
原文要素は固定されない。時と場合によって、向く面を変える。

第三法則　保存LEX III · CONSERVATIO　負は滅せず、積もる。一たび向けたる負は取り消されず、蓄積は減ずることなし。
原文負は消えない。蓄積する。

第四法則　反転LEX IV · CONVERSIO　負の蓄積進みて、その人の閾に達すれば、かつて負を向けたる面の逆、正として顕る。
原文負の蓄積が進めば、逆の面が正として顕れる。

第五法則　目安LEX V · NORMA　三十歳は目安に過ぎず。切り替はりは、その齢に先だつこともあり。
原文三十歳は目安にすぎない。切り替わりは年齢に先立つことがある。

第六法則　還元LEX VI · RESTITUTIO　成果は、出づるその時に、人の関係へ事もなく還る。故に外よりは見えず。
原文成果は、出た瞬間に社会的関係へ何事もなく還元される。ゆえに外からは見えない。

第七法則　共通LEX VII · COMMUNITAS　成れる者は、皆これを行ふ。すなはち、魔法使ひと成りし後は、命ある限り、成果を生む能動を止めず。
原文成った者は、皆これを行っている。

第八法則　泥沼LEX VIII · PALUS　成れば泥沼なり。成りし後、脳は止まず。
原文成れば泥沼である。脳は止まらない。

第九法則　秘匿LEX IX · ARCANUM　具体を記せば、記したる者に害返る。故に具体は記さず。
原文具体を記せば、記した者に害が返る。ゆえに具体は記さない。

第十法則　長命LEX X · LONGAEVITAS　成るは、長く生くることなり。長く生くるは難し。その労は、生きたる長さと共に増す。
原文成ることは、長く生きることである。長く生きるのは大変である。
注ここに長く生くとは遊びの語にして、身体の寿命を言ふにあらず。

定理PROPOSITIONES

定理一　魔法使ひたるか否かは、成果を以て外より見分くるを得ず。
証明第六法則により、成果は外より見えず。しかるに定義一は、成果を出だすことを求む。故に外よりは、この条件を成果を以て確かむるを得ず。Q.E.D.

定理二　第一法則は足る条件にして、要る条件にあらず。すなはち、童貞ならざる者も魔法使ひたり得。
証明童貞を条件とするは第一法則のみにして、それも童貞なる者の行く末を述ぶるに止まる。定義一は童貞を含まず。現に、第二巻の模型 M₀′ にては、x は童貞ならずして、時二十一にて魔法使ひと成り、いづれの法則にも背かず（定理十）。故に、童貞ならざる魔法使ひあり得。Q.E.D.

定理三　この法則は、三十歳の誕生日に何事かの起こるを言はず。
証明第一法則は、いつか必ず成ると言ふのみにして、その時の三十歳の前なるも後なるも妨げず。第五法則もまた、三十歳を目安と言ふのみ。定義九により、目安は時を定めず。Q.E.D.

定理四　この法則は、外より成果を観て反証するを得ず。
証明第一法則の外れたる例を示すには、三十歳に至るまで童貞なる者の、魔法使ひと成らざることを示さざるべからず。しかるに第六法則により、成果は外より見えず。成果の見えざるは、成らざるの証とならず。故に、外より成果を観て、外れたる例を示すを得ず。Q.E.D.
注この法則の、科学の法則にあらざる所以の一つ、ここに在り。式の上の証は、第二巻の定理十一に在り。

定理五　魔法使ひは、他の人に優るにあらず。
証明要請二により、人の値は魔法使ひたると否とに由らず。故に、魔法使ひたることより、人の上下を導くを得ず。Q.E.D.
注ここに優るにあらずとは、魔法使ひたるが故に優るにあらざるを謂ふ。

定理六　正四面体の面の逆は、頂点なり。
証明正四面体の中心を原点に置けば、四つの頂点の和は零なり。一つの面の中心は残る三つの頂点の平均なれば、その面に向かひ合ふ頂点を v とするとき、−v/3 なり。すなはち面の中心は、四つの頂点の各々の −1/3 倍なり。これを中心について点対称に移せば v/3 となる。v に点対称なる頂点なきが故に、v/3 はいづれの面の中心にも等しからず。故に正四面体には逆の面なく、定義十により、逆は向かひ合ふ頂点なり。他の四つの正多面体は中心について点対称なれば、いづれの面にも逆の面あり。Q.E.D.

定理七　面の数 n なる要素にて、面ごとの負正の割り当ては 2ⁿ 通りなり。
証明各面に負と正との二つあり。面の数 n なれば、割り当ては 2ⁿ 通りなり。正二十面体は面二十なれば、2²⁰ すなはち 1,048,576 通りなり。Q.E.D.

注解SCHOLIUM

  • 凡そ正多面体の五つに限ることは、ユークリッド『原論』第十三巻の終はりに証せらる。プラトンの『ティマイオス』に因みて、プラトンの立体とも呼ばる。
  • この版の並びは、ニュートン『自然哲学の数学的原理』（一六八七年）に倣ふ。かの書は、定義と、それに続く注解との次に「公理、すなはち運動の法則」を置き、法則の後に系と注解とを置く。
  • この版にて補へるもの：定義一の後段（時を異にする面）、定義二の時の限りと値の語、定義六の面の負正、定義七の量、定義八の時の名、定義九の後段、定義十（逆と、その頂点の負正）、要請一・二、第一法則の「いつか必ず」と時の前後、第四法則の閾、第七法則と第八法則の「成りし後」の読み、第十法則の労の増し方と注。いづれも原典に無く、Claude の書けるものなり。

定理八　定義六と十の法則とは、相容る。
証明次の模型 M₀ を取る。P = {x}、C = {c}、L(x) = 100、Λ = 80、κ(x) = 1、V(x, t) は常に真。E(x) = {e} で、e は正六面体。g、f、f* は e の面で、f* = ι(f)、g はそのどちらとも異なる。φ(e, t, c) は、t < 20 で g、t = 20 で f、t > 20 で f*。σ(u, t, c) は、t = 20 で −、ほかで +。N = H。Act(x) = {a_s : 21 ≤ s ≤ 100}、τ(a_s) = s、U(a_s) = {(e, 20, c), (e, s, c)}、R(a_s) = {r_s}。Rel(x) = {r_s}、Obs = ∅、B は常に真、Wr = ∅、Toil(x, t) = t。このとき H(x, t) は t ≥ 20 で {(e, 20, c)} となり、A は時 20 に閾に達し、Sw(x, 21) が成り立ち、W(x, t) は t ≥ 21 で成り立つ。D6 と L1〜L10 のそれぞれに代入すれば、すべて真となる。Q.E.D.

定理九　十の法則は、互いに独立なり。いづれの一つも、他の九つと定義六とより導かれず。
証明k = 1, …, 10 の各々に、L_k だけを偽とし、D6 と他の九つを真とする模型 M_k を、M₀ を改めて作る。M_k が L_k を満たさず、残りを満たすので、L_k は残りから導かれない。Q.E.D.

定理十　外より見ゆるものを等しくして、魔法使ひたると否とのみ異なる二つの模型あり。
証明M₀⁻ を、M₀ から能動を除き（Act(x) = ∅、Rel(x) = ∅）、V(x, t) を常に偽としたものとする。V が偽なので L1 は空しく真、W が偽なので L7・L8 も空しく真、切り替わりは残るので L4・L5 も真。ゆえに M₀⁻ は D6 と十の法則を満たす。M₀ と M₀⁻ とで Obs はともに空だが、W(x, 100) は M₀ で真、M₀⁻ で偽。また、M₀ で V を常に偽としたもの M₀′ も十の法則を満たし、そこで x は童貞ならずして魔法使いとなる。これが第一巻の定理二の式の上の証である。Q.E.D.

定理十一　生きる長さと労とを外より見えざるものとすれば、外より見ゆるもののいかなる記録も、第一法則を反証せず。これを外より見ゆるものとすれば、反証は得らる。
証明前半。M を、第一法則のほかの九つと D6 とを満たす模型とし、三十歳まで童貞で魔法使いと成らない人を x とする。x の内のもの、すなわち E、φ、x の面の σ、N、κ、Act、Rel、B、Toil、L を、M₀ の x のものに取り替え、V(x) と、他の人と、Obs とは残す。取り替えた x は M₀ の x と同じく十の法則を満たし、新しい成果は Obs の外にある。これをそうした人の全てに行えば、Obs の同じ模型で第一法則が成り立つ。ゆえに、Obs のどの記録も、第一法則の成り立つ世界と成り立たない世界とを分けない。後半。L(x) が外から見えるなら、L1 と L10 から、三十歳まで童貞で生きる者は Λ まで生きる、という外から見える帰結が出る。L(x) < Λ で世を去った例が一つあれば、これを反証する。Q.E.D.
注第十法則の注は、L を外より見えざる遊びの語と定め、後半の帰結を断つ。この帰結は身体の寿命についての主張となるため、この遊びは、注によって、それを主張しない。

定理十二　正多面体のいづれの面にも逆の面あるは、その対称の群に中心反転 −I の属する時に限る。五つの中、これを欠くは正四面体のみ。
証明−I が対称の群 G に属すなら、−I は面を面に移し、面の中心 p を −p に移すので、−p を中心とする面が p の面の逆である。逆に、どの面にも逆があれば、面の中心の集まりは中心対称となる。面の中心は双対の多面体の頂点を指し、双対の対称の群は G と同じなので、−I は G に属する。正四面体では、定理六により −p はどの面の中心でもない。ゆえに、その対称の群 T_d（S₄ と同じ形、位数 24）は −I を含まない。正六面体と正八面体の群 O_h（S₄ × C₂、位数 48）、正十二面体と正二十面体の群 I_h（A₅ × C₂、位数 120）は、−I を含む。Q.E.D.

定理十三　回転にて重なる割り当てを同じと見れば、面ごとの負正の割り当ては、正四面体 5、正六面体 10、正八面体 23、正十二面体 96、正二十面体 17,824 通りなり。
証明バーンサイドの補題により、数は回転の群 G での平均 (1/#G) Σ_g 2^{c(g)} に等しい。c(g) は、g が面に作る巡回の数である。回転の群の位数は、順に 12、24、24、60、60。
正四面体：(2⁴ + 8·2² + 3·2²)/12 = 60/12 = 5。
正六面体：(2⁶ + 6·2³ + 3·2⁴ + 8·2² + 6·2³)/24 = 240/24 = 10。
正八面体：(2⁸ + 6·2² + 3·2⁴ + 8·2⁴ + 6·2⁴)/24 = 552/24 = 23。
正十二面体：(2¹² + 24·2⁴ + 20·2⁴ + 15·2⁶)/60 = 5,760/60 = 96。
正二十面体：(2²⁰ + 24·2⁴ + 20·2⁸ + 15·2¹⁰)/60 = 1,069,440/60 = 17,824。Q.E.D.

総注解SCHOLIUM GENERALE

  • 式に移すときの読み。第二法則は「すべての要素」と読み、第五法則は「ある者」と読み、第一法則は「生きているあいだに」と読んだ。第二法則を「ある要素」と読めば、それは第五法則と定義八とから導かれ、独立ではなくなる。切り替わりは、ある要素が面 f のあとに、それと異なる f の逆を向けることだからである。
  • 要請二は、人の値についての規範であって、事実を述べる式の体系の外に置いた。「である」から「べきである」は導かれない。そのため、値は式で証すのではなく、要請として先に置く。
  • 長命の境 Λ と、外から見えるもの Obs は、法則が定めず、模型が定める。どちらを動かしても、定理八から十一は成り立つ。
  • 「総注解」の名は、ニュートン『自然哲学の数学的原理』の第二版（1713 年）が巻末に足した Scholium Generale に倣った。
