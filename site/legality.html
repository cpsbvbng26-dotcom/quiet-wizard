この頁の位置づけ

このサイトが日本の法令のどこに触れうるかと、触れないために決めていることを並べた頁です。
運営者の側の理解を書いたもので、読む人への法的な助言ではありません。
弁護士の確認は受けていません。
引く条文は、運営者の別のリポジトリの見張りが e-Gov 法令 API から取り寄せて記した文を、そのまま写しています（下の「条文」）。法令の文を記憶から書いてはいません。
日本の外の法令は、調べていません。
書体・印・ファビコン・図・配色など、見た目の部品の扱いは、デザインに関する法的な扱いに分けて書いています。

前提となる事実

  • サイトは静的な頁と、ブラウザの中だけで動く遊び場です。何も集めず、何も売らず、広告も寄付もありません。
  • 原典は運営者の文で、遊びの部分は運営者の求めで Claude が書きました。他人の著作物を写していません。
  • 特定の人の名を挙げず、実在の人を例にしません。
  • 性的な描写を含みません。
  • みんなの図鑑には、読む人が GitHub の issue で寄せ、運営者が読んで選んだ場面だけを載せます。頁そのものは、何も受け取りません。寄せた場面は、寄せた人の文です。

条ごとの整理

法令触れうる道このサイトの決め
刑法 第230条・第231条人を魔法使いだと言い立てたり、性経験を言いふらしたりすること特定の人を挙げない。図鑑の「見分け方」で、身の回りの人に当てはめることは遊びの外だと書く。利用規約で、人を言い立てる使い方を想定していないと示す
刑法 第233条虚偽の風説で人の信用を損なうこと人や事業者を挙げない
民法 第709条人の権利や利益を侵すこと上の二つと同じ。人の情報を集めない
著作権法 第21条・第23条他人の著作物を写し、送信すること原典は運営者の文。遊びの文と図は Claude が新しく書き、ほかの作品を写していない。図は直線・円・多角形だけで新しく描いた。配る書体は、SIL Open Font License 1.1 の英字書体 Inter Tight だけで、許諾の文を添える
景品表示法 第5条商品や役務の取引で、実際より良く見せる表示何も売らず、取引がない。魔法使いの認定のようなものを出さない
消費者契約法 第10条消費者の利益を一方的に害する条項読む人には同意の手続きを置かず、利用規約を契約の条項として結ばない。場面を寄せる人が様式で付ける印は、寄せた文の許諾と、決めた三つの直しへの同意と、年齢などの確かめで、運営者はこれを、利用規約を契約の条項とする合意としては扱わない。運営者の責任は法令のとおりとし、法令が認める以上に軽くしない。消費者契約に当たるかを定める条（第2条）は引いていない
民法 第548条の2定型約款の合意読む人には同意の手続きを置かない。利用規約を合意の内容とする仕組みがない。場面を寄せる人の印も、利用規約を合意の内容とするものとしては置いていない
商標法 第25条他人の登録商標を、同じ商品や役務に使うこと登録の有無は調べていないと書き、権利者から知らせがあれば名を変えるか使うのをやめる。出願しないことは、この道を避ける手段ではない

参加（みんなの図鑑）の法的な扱い

みんなの図鑑では、読む人が GitHub の issue の様式で場面を寄せ、運営者が読んで選んだものだけを頁に載せます。
この節は、その参加の形が触れうる法令と、決めていることと、残ることを、危うさごとに並べます。
ここも、運営者の側の理解を書いたもので、弁護士の確認は受けていません。
引く条文は、上の「この頁の位置づけ」に書いた写しにある条だけです（下の「条文」）。
写しに無い法令と条は、名と番号だけを挙げます。
写しに無い法令と条の文は、取り寄せておらず、確かめていません。

危うさ関わる法令このサイトの決め残ること
第三者の名誉とプライバシー刑法 第230条・第231条、民法 第709条。写しに無いもの：民法 第723条。裁判所の判断が認めてきたプライバシーの利益様式の印で、実在の人や誰のことか分かる人を、名指しも描写もしないことを求める。載せる前に運営者が読み、人を指しうる場面は載せない。受付の機械は、敬称や続柄の後の「は魔法使い」、GitHub の名、リンクなど、決めた語の形を拾う。載せた場面は、求めがあれば外す。issue は、運営者が本文を直すか消す決めた語の形に当たらない書き方で人を指す文は、機械では拾えない。運営者が読むまでのあいだ、issue には書かれたとおりに残る
読む前から公開される issue上と同じ様式の初めの欄と場面の欄の説明に、issue が開いたその時から公開されることを書く。運営者は、決めに触れる issue を見つけしだい、求めを待たずに本文を直すか issue を消す。求め方は求めと連絡にあるissue を開いてから運営者が読むまでの時間は、決められない。GitHub の編集の履歴と、GitHub の外へ写されたものは、運営者には消せないことがある
寄せた文の著作権著作権法 第21条・第23条様式の印で、自分で新しく書いた文で、他人の文や作品を写していないことと、文を CC BY 4.0 で許諾することを求める。著作権は寄せた人に残る。権利者から知らせがあれば、判断の前にその場面を外す写したかどうかを、運営者は確かめきれない
著作者人格権著作権法 第19条・第20条運営者が手を入れるのは、寄せた人が様式の印で同意した三つ（長さを詰めること、表記をそろえること、このサイトの決めに合わない語を替えること）に限る。意味の変わる直しは、その issue で尋ね、同意があってからにする。手を入れた場面には、そのことを頁に記す。著作者人格権を行使しないことは求めない。名の表示は、寄せた人の「名の表示」の印のとおりにし、印が無ければ名を出さない三つの直しのどれに当たるかの線引きは、運営者の読みによる。寄せた人は、手を入れた場面を外すことを求められる
性を題材にした遊びと、未成年条は挙げない。性的な描写を載せないことと、年齢の印は、このサイトの決めとして置く様式の印で、十八歳以上であることを求める。誰の性経験にも触れず、性的な描写もないことを印で求め、受付の機械も決めた語を拾う。性的な描写のある場面は載せない年齢は印だけで、確かめる手段は無い
個人情報写しに無いもの：個人情報の保護に関する法律（個人情報保護法）、その第28条（外国にある第三者への提供）扱うのは、issue を開いた人の GitHub の名と、issue に書かれたこと。目的は、場面を読み、載せるかを決め、載せ、求めに答えることだけ。名を頁に出すのは、「名の表示」の印があるときだけ。題と本文を Claude（Anthropic、米国）に渡すのは、同意の印があるときだけで、第28条の外国にある第三者への提供として扱う。求めがあれば、載せた場面と名を外す。issue は GitHub（米国）が自分の決まりで持つ（個人情報の取り扱い）この法律の文は写しに無く、条ごとの当てはめは確かめていない
発信する者と、場を出す者の責任写しに無いもの：情報流通プラットフォーム対処法（以前の通称はプロバイダ責任制限法）issue の場は GitHub が出す。サイトに載せた場面は、運営者が読んで選んで載せたものなので、運営者が自分で載せたものと同じに扱う。この頁は、この法律が運営者の責任を軽くするとは考えない。権利を侵すという知らせは求めと連絡で受け、判断の前に、その場面を頁から外し、issue の本文を直すか issue を消すこの法律の文は取り寄せておらず、運営者がこの法律のどの立場に当たるか、どの手続きが掛かるかを確かめていない
差別と、人を傷つける書き方刑法 第231条、民法 第709条人をからかう場面、誰かを狙う場面、人を属性で分ける場面は載せない。様式の印で、誰も魔法使いと呼ばないことを求める載せない判断は、運営者の読みによる
対価と賞品景品表示法 第5条寄せた人に対価も賞品も出さない。寄せる人から料金を取らない。載せることは賞ではない。何も売らないなし

写しに無い法令と条（民法 第723条、個人情報保護法とその第28条、情報流通プラットフォーム対処法）は、名と番号だけを挙げています。条文は取り寄せておらず、確かめていません。

規約の外で、法令に触れうる行い

このサイトの文を使って、実在の人を魔法使いだと言い立てたり、性経験を話題にしてからかったりすることは、上の刑法と民法の条に触れうる行いです。
利用規約は、そうした使い方を想定していないと示しています。
このサイトが、そうした行いを勧めることはありません。

条文

刑法 第230条

（名誉毀損） 第二百三十条 公然と事実を摘示し、人の名誉を毀損した者は、その事実の有無にかかわらず、三年以下の拘禁刑又は五十万円以下の罰金に処する。 ２ 死者の名誉を毀損した者は、虚偽の事実を摘示することによってした場合でなければ、罰しない。

刑法 第231条

（侮辱） 第二百三十一条 事実を摘示しなくても、公然と人を侮辱した者は、一年以下の拘禁刑若しくは三十万円以下の罰金又は拘留若しくは科料に処する。

刑法 第233条

（信用毀損及び業務妨害） 第二百三十三条 虚偽の風説を流布し、又は偽計を用いて、人の信用を毀損し、又はその業務を妨害した者は、三年以下の拘禁刑又は五十万円以下の罰金に処する。

民法 第709条

（不法行為による損害賠償） 第七百九条 故意又は過失によって他人の権利又は法律上保護される利益を侵害した者は、これによって生じた損害を賠償する責任を負う。

著作権法 第21条

（複製権） 第二十一条 著作者は、その著作物を複製する権利を専有する。

著作権法 第23条

（公衆送信権等） 第二十三条 著作者は、その著作物について、公衆送信（自動公衆送信の場合にあつては、送信可能化を含む。）を行う権利を専有する。 ２ 著作者は、公衆送信されるその著作物を受信装置を用いて公に伝達する権利を専有する。

景品表示法 第5条

（不当な表示の禁止） 第五条 事業者は、自己の供給する商品又は役務の取引について、次の各号のいずれかに該当する表示をしてはならない。 一 商品又は役務の品質、規格その他の内容について、一般消費者に対し、実際のものよりも著しく優良であると示し、又は事実に相違して当該事業者と同種若しくは類似の商品若しくは役務を供給している他の事業者に係るものよりも著しく優良であると示す表示であつて、不当に顧客を誘引し、一般消費者による自主的かつ合理的な選択を阻害するおそれがあると認められるもの 二 商品又は役務の価格その他の取引条件について、実際のもの又は当該事業者と同種若しくは類似の商品若しくは役務を供給している他の事業者に係るものよりも取引の相手方に著しく有利であると一般消費者に誤認される表示であつて、不当に顧客を誘引し、一般消費者による自主的かつ合理的な選択を阻害するおそれがあると認められるもの 三 前二号に掲げるもののほか、商品又は役務の取引に関する事項について一般消費者に誤認されるおそれがある表示であつて、不当に顧客を誘引し、一般消費者による自主的かつ合理的な選択を阻害するおそれがあると認めて内閣総理大臣が指定するもの

消費者契約法 第10条

（消費者の利益を一方的に害する条項の無効） 第十条 消費者の不作為をもって当該消費者が新たな消費者契約の申込み又はその承諾の意思表示をしたものとみなす条項その他の法令中の公の秩序に関しない規定の適用による場合に比して消費者の権利を制限し又は消費者の義務を加重する消費者契約の条項であって、民法第一条第二項に規定する基本原則に反して消費者の利益を一方的に害するものは、無効とする。

商標法 第25条

（商標権の効力） 第二十五条 商標権者は、指定商品又は指定役務について登録商標の使用をする権利を専有する。 ただし、その商標権について専用使用権を設定したときは、専用使用権者がその登録商標の使用をする権利を専有する範囲については、この限りでない。

民法 第548条の2

（定型約款の合意） 第五百四十八条の二 定型取引（ある特定の者が不特定多数の者を相手方として行う取引であって、その内容の全部又は一部が画一的であることがその双方にとって合理的なものをいう。以下同じ。）を行うことの合意（次条において「定型取引合意」という。）をした者は、次に掲げる場合には、定型約款（定型取引において、契約の内容とすることを目的としてその特定の者により準備された条項の総体をいう。以下同じ。）の個別の条項についても合意をしたものとみなす。 一 定型約款を契約の内容とする旨の合意をしたとき。 二 定型約款を準備した者（以下「定型約款準備者」という。）があらかじめその定型約款を契約の内容とする旨を相手方に表示していたとき。 ２ 前項の規定にかかわらず、同項の条項のうち、相手方の権利を制限し、又は相手方の義務を加重する条項であって、その定型取引の態様及びその実情並びに取引上の社会通念に照らして第一条第二項に規定する基本原則に反して相手方の利益を一方的に害すると認められるものについては、合意をしなかったものとみなす。

著作権法 第19条（第1項の第一文と第2項）

（氏名表示権） 第十九条 著作者は、その著作物の原作品に、又はその著作物の公衆への提供若しくは提示に際し、その実名若しくは変名を著作者名として表示し、又は著作者名を表示しないこととする権利を有する。

２ 著作物を利用する者は、その著作者の別段の意思表示がない限り、その著作物につきすでに著作者が表示しているところに従つて著作者名を表示することができる。

長い条なので、第1項の第一文と第2項だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。

著作権法 第20条（第1項）

（同一性保持権） 第二十条 著作者は、その著作物及びその題号の同一性を保持する権利を有し、その意に反してこれらの変更、切除その他の改変を受けないものとする。

長い条なので、第1項だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。
