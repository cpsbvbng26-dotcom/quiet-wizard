この頁について

このサイトの見た目の部品を、一つずつ挙げた頁です。
部品ごとに、誰が作ったか、どこから来たか、権利と許諾がどうなっているか、日本の法令のどの条に関わりうるかを書きます。
部品は、書体、印、ファビコン、場面と図、配色と配置の指定、遊び場の絵を描くスクリプトです。
運営者の側の理解を書いたもので、読む人への法的な助言ではありません。
弁護士の確認は受けていません。
引く条文は、運営者の別のリポジトリの見張りが e-Gov 法令 API から取り寄せて記した文を、そのまま写しています（下の「条文」）。法令の文を記憶から書いてはいません。
日本の外の法令は、調べていません。
サイト全体と法令との関わりは、適法性の説明にあります。

書体

配る書体

配る書体は Inter Tight だけです。
style.css の @font-face で、このサイトのファイル（assets/intertight.woff2）から読みます。
書体を読んでよい所は、このサイトだけです（CSP の font-src 'self'）。
収める字は 103 字です。
ASCII の 95 字（U+0020〜U+007E）と、記号の 8 字（U+00B7、U+2013、U+2014、U+2018、U+2019、U+201C、U+201D、U+2026）です。
かなと漢字は入っていません。
和文は、読む人の端末の書体で表示されます。

名指すだけの書体

style.css の書体の並びと、GitHub で見る図の中の指定は、端末にあれば使う書体の名を挙げています。
このサイトは、これらの書体のファイルを配っていません。名を書いているだけです。

名指す書体：Helvetica Neue、Arial、Hiragino Mincho ProN、Yu Mincho、YuMincho、Noto Serif JP、Noto Serif CJK JP、Hiragino Sans、Yu Gothic UI、Yu Gothic、Noto Sans JP。
端末の標準の書体を指す語：system-ui、-apple-system、serif、sans-serif。

外から読む素材

外から読む素材はありません。
頁は、ほかのサーバーへ何も要求しません（CSP の default-src 'none'）。
書体、画像、スクリプト、様式は、どれもこのサイトから読みます。

著作権

意匠が著作物に当たるか

著作権法は、著作物を「思想又は感情を創作的に表現したもの」で、文芸、学術、美術または音楽の範囲に属するものとしています（第2条第1項第1号）。
美術の著作物は、著作物の例に挙がっています（第10条第1項第4号）。
このサイトの印、ファビコン、場面、図は、運営者の求めで Claude が描いた図形です。
言語モデルが描いた図形がこの定めに当たるかは、条文の文からは決まりません。
この頁は、当たるとも当たらないとも決めません。
当たる部分があれば、その部分は上の許諾で使えます。

著作者人格権

氏名表示権（第19条）と同一性保持権（第20条）は、著作者の権利です。
このサイトは、Claude を著者としていません。
図に、著作者の名は記していません。

書体については、書体の著作権の行が示す名（The Inter Project Authors）を、断りと開示の頁と許諾の文に、そのまま示しています。
第19条第2項は、著作物を利用する者は「すでに著作者が表示しているところに従つて著作者名を表示することができる」としています。

書体を英字だけに絞ったことは、書体の一部を削ることに当たります。
許諾の文は、書体を改めることを許しています。

to use, study, copy, merge, embed, modify, redistribute, and sell modified and unmodified copies of the Font Software

許諾の文は、削って作ったものを Modified Version と呼んでいます。

"Modified Version" refers to any derivative made by adding to, deleting, or substituting -- in part or in whole -- any of the components of the Original Version

書体がこの法の著作物に当たるかも、この頁は決めません。

書体の許諾の条件

  • 書体を単体で売らないこと（条件 1）：このサイトは、何も売りません。
  • 著作権の表示と許諾の文を添えること（条件 2）：許諾の文を assets/OFL-InterTight.txt として配り、書体のファイルの名前表にも著作権の欄（nameID 0）と許諾の欄（nameID 13）を残しています。
  • 予約された書体名（条件 3）：許諾の文の著作権の行に、予約された書体名（Reserved Font Name）の定めはありません。絞った写しは、名を Inter Tight のままにしています。
  • 同じ許諾で配ること（条件 5）：書体は、この許諾だけで配ります。CC BY 4.0 にも MIT にも入れていません。

他人の素材

書体のほかに、他人の作った素材は使っていません。
写真やラスターの画像（PNG、JPEG、GIF、WebP、ICO など）は、リポジトリに一枚もありません。
SVG は、svg、g、path、polygon、circle、ellipse、rect、line、text の要素だけで組んでいます。
画像の埋め込みも、ほかのファイルへの参照も持ちません。
遊び場のスクリプトが描く要素は、circle と line だけです。

商標・意匠・不正競争

出願と登録

サイトの名（ステルス・ウィザード、地味な魔法使い、quiet-wizard）は、商標として出願していません（利用規約の「名称」）。
印、ファビコン、場面、図を、商標や意匠として出願したという記録は、このリポジトリにありません。
同じ名や似た名、似た形の商標や意匠が登録されているかは、特許庁のデータベースで調べていません。

意匠法

意匠法は、画像を意匠に含めます。
ただし、画像は「機器の操作の用に供されるもの又は機器がその機能を発揮した結果として表示されるもの」に限られます（第2条第1項）。
このサイトの場面や図がこれに当たるかを、この頁は決めません。
意匠権の効力は、「業として」の実施に及びます（第23条）。
このサイトは何も売らず、誰からも料金を取りません。
それで「業として」に当たらないと言えるかも、条文の文からは決まりません。
他人の登録意匠と似ていないかは、照らし合わせていません。

商標法

商標権者は、「指定商品又は指定役務について登録商標の使用をする権利を専有する」とされています（第25条）。
このサイトは、Inter Tight の名を、書体の名として示すだけです。
自分の商品や役務の名にはしていません。
書体のファイルの名前表（nameID 7）には、Inter の名が商標だという記載があります。
ほかの書体の名（上の「名指すだけの書体」）も、端末の書体を選ぶために書いているだけです。

不正競争防止法

第2条第1項第1号と第2号は、他人の「商品等表示」と同一か類似の表示を使う行為を挙げています。
第3号は、他人の「商品の形態」を「模倣した商品」を、譲渡したり、電気通信回線を通じて提供したりする行為を挙げています。
このサイトの名、印、ファビコン、場面、図は、他人の表示や画像を写して作ったものではありません。
上の「他人の素材」のとおり、図形の要素だけで描いています。
描いた形が、他人の広く知られた表示や商品の形態に似ていないかは、照らし合わせていません。
権利者から知らせがあれば、部品を描き直すか、使うのをやめます（求めと連絡）。

見やすさ

障害を理由とする差別の解消の推進に関する法律（障害者差別解消法）は、「事業者」を「商業その他の事業を行う者」としています（第2条第7号）。
そして事業者に、障害を理由とする「不当な差別的取扱い」をしないことと、社会的障壁の除去について「必要かつ合理的な配慮」をすることを求めています（第8条）。
運営者がこの法の「事業者」に当たるかは、条文の文からは決まりません。
この頁は、当たるとも当たらないとも決めません。

そのうえで、このサイトが見た目についてしていることのうち、検査が確かめている事柄を挙げます。

  • 文字の色（--ink、--muted、--accent、--gold）と地の色（--bg、--tint）の比は、明るい配色でも暗い配色でも 4.5 以上です。いちばん低いのは、明るい配色の --muted と --tint の 5.73 です。
  • 上の欄の文字の色（--mastink、--mastmuted、--mastgold）と地の色（--mastbg）の比も 4.5 以上です。上の欄は、どちらの配色でも同じ色です。
  • 遊び場の網の線と点の色と、二つの目の地の色の比は、3 以上です。遊び場の網で、いちばん低いのは、魔法使いの目の #5d6672 と地の #12161c の 3.12 です。
  • 図の中の文字は、形を色の名で指しません。図の線の色は、暗い配色で明るく変わるためです。
  • 動きを減らす設定（prefers-reduced-motion）のときは、style.css の animation をすべて止め、はじめにの場面の切り替えの移り変わりも止めます。遊び場の「自動で過ごす」は、一日の間を 800 ミリ秒から 1500 ミリ秒に延ばします。
  • 頁の中の画像には、代わりの文を付けています。img には alt を、図と場面と遊び場の網には aria-label を付け、飾りの SVG は aria-hidden で読み上げから外します。
  • キーボードで動かす部品には、フォーカスの輪（:focus-visible の 2px の線）を描きます。
  • どの頁にも、本文へ飛ぶつなぎ（「本文へ」）を、頁の初めに置いています。キーボードで選んだときだけ見えます。
  • 印刷では、上の帯と上の欄とクラス表を、白地の黒字にします。
  • 拡大を止めていません。viewport の指定に、maximum-scale も user-scalable も書いていません。

次のことは、確かめていません。

  • 頁の中に直に書いた色（上の帯、クラス表、場面）の比。
  • 背景の色の滲みを重ねた所の比。
  • 図の文字のほかで、色だけに頼らずに読めるか。
  • 読み上げの道具で、どう読まれるか。

人と団体

部品に、実在の人の肖像は描いていません。
はじめにの場面の人は、線で描いた、誰でもない人です。
実在の団体の印やロゴも置いていません。
配信をする Vercel の印も、書体の作り手の印もありません。
写真や他所の画像を取り込んでいないことは、検査が確かめています（上の「他人の素材」）。

変わったとき

部品を変えるときは、この頁と検査を、同じ変更（同じ PR）で直します。
部品のファイルを足すか外すと、上の表と合わなくなり、検査が落ちます。
書体を差し替えると、中身の SHA-256 が合わなくなり、検査が落ちます。
変えるときは、最終更新の日を改めます。前の版はリポジトリの履歴に残ります。

条文

著作権法 第2条第1項第1号

一 著作物 思想又は感情を創作的に表現したものであつて、文芸、学術、美術又は音楽の範囲に属するものをいう。

著作権法 第10条第1項第4号

四 絵画、版画、彫刻その他の美術の著作物

著作権法 第19条（第1項の第一文と第2項）

（氏名表示権） 第十九条 著作者は、その著作物の原作品に、又はその著作物の公衆への提供若しくは提示に際し、その実名若しくは変名を著作者名として表示し、又は著作者名を表示しないこととする権利を有する。

２ 著作物を利用する者は、その著作者の別段の意思表示がない限り、その著作物につきすでに著作者が表示しているところに従つて著作者名を表示することができる。

長い条なので、第1項の第一文と第2項だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。

（同一性保持権） 第二十条 著作者は、その著作物及びその題号の同一性を保持する権利を有し、その意に反してこれらの変更、切除その他の改変を受けないものとする。

長い条なので、第1項だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。

意匠法 第2条（第1項）

（定義等） 第二条 この法律で「意匠」とは、物品（物品の部分を含む。以下同じ。）の形状、模様若しくは色彩若しくはこれらの結合（以下「形状等」という。）、建築物（建築物の部分を含む。以下同じ。）の形状等又は画像（機器の操作の用に供されるもの又は機器がその機能を発揮した結果として表示されるものに限り、画像の部分を含む。次条第二項、第三十七条第二項、第三十八条第七号及び第八号、第四十四条の三第二項第六号並びに第五十五条第二項第六号を除き、以下同じ。）であつて、視覚を通じて美感を起こさせるものをいう。

長い条なので、第1項だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。

意匠法 第23条

（意匠権の効力） 第二十三条 意匠権者は、業として登録意匠及びこれに類似する意匠の実施をする権利を専有する。 ただし、その意匠権について専用実施権を設定したときは、専用実施権者がその登録意匠及びこれに類似する意匠の実施をする権利を専有する範囲については、この限りでない。

商標法 第25条

（商標権の効力） 第二十五条 商標権者は、指定商品又は指定役務について登録商標の使用をする権利を専有する。 ただし、その商標権について専用使用権を設定したときは、専用使用権者がその登録商標の使用をする権利を専有する範囲については、この限りでない。

不正競争防止法 第2条第1項第1号・第2号

一 他人の商品等表示（人の業務に係る氏名、商号、商標、標章、商品の容器若しくは包装その他の商品又は営業を表示するものをいう。以下同じ。）として需要者の間に広く認識されているものと同一若しくは類似の商品等表示を使用し、又はその商品等表示を使用した商品を譲渡し、引き渡し、譲渡若しくは引渡しのために展示し、輸出し、輸入し、若しくは電気通信回線を通じて提供して、他人の商品又は営業と混同を生じさせる行為 二 自己の商品等表示として他人の著名な商品等表示と同一若しくは類似のものを使用し、又はその商品等表示を使用した商品を譲渡し、引き渡し、譲渡若しくは引渡しのために展示し、輸出し、輸入し、若しくは電気通信回線を通じて提供する行為

不正競争防止法 第2条第1項第3号

三 他人の商品の形態（当該商品の機能を確保するために不可欠な形態を除く。）を模倣した商品を譲渡し、貸し渡し、譲渡若しくは貸渡しのために展示し、輸出し、輸入し、又は電気通信回線を通じて提供する行為

障害者差別解消法 第2条（柱書きと第1号・第2号・第7号）

（定義） 第二条 この法律において、次の各号に掲げる用語の意義は、それぞれ当該各号に定めるところによる。

一 障害者 身体障害、知的障害、精神障害（発達障害を含む。）その他の心身の機能の障害（以下「障害」と総称する。）がある者であって、障害及び社会的障壁により継続的に日常生活又は社会生活に相当な制限を受ける状態にあるものをいう。

二 社会的障壁 障害がある者にとって日常生活又は社会生活を営む上で障壁となるような社会における事物、制度、慣行、観念その他一切のものをいう。

七 事業者 商業その他の事業を行う者（国、独立行政法人等、地方公共団体及び地方独立行政法人を除く。）をいう。

長い条なので、柱書きと第1号・第2号・第7号だけを、写しの文から一字一句そのまま切り出しています。ほかの項と号は省いています。

障害者差別解消法 第8条

（事業者における障害を理由とする差別の禁止） 第八条 事業者は、その事業を行うに当たり、障害を理由として障害者でない者と不当な差別的取扱いをすることにより、障害者の権利利益を侵害してはならない。 ２ 事業者は、その事業を行うに当たり、障害者から現に社会的障壁の除去を必要としている旨の意思の表明があった場合において、その実施に伴う負担が過重でないときは、障害者の権利利益を侵害することとならないよう、当該障害者の性別、年齢及び障害の状態に応じて、社会的障壁の除去の実施について必要かつ合理的な配慮をしなければならない。
