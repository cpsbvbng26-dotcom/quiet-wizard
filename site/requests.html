Requests & Contact

最終更新：2026-11-21（変更の記録）。

受けるもの

  • 文の誤りの知らせ。
  • 自分についての記載を消すこと、直すことの求め。
  • 名や図や文が権利を侵している、という権利者からの知らせ。
  • 安全の問題の知らせ。

どれも、費用はかかりません。どの国の人からも受けます。

求め方

リポジトリの issue を開きます。
issue は公開されます。個人の情報や、安全の問題の詳しいことは書かずに、「非公開の連絡を求める」とだけ書くことができます。
そのときは、知らせた人が自分の GitHub のプロフィールに連絡先を公開していれば、運営者がその連絡先へ非公開で答えます。
連絡先を公開しないときは、運営者は詳しいことに触れずに issue で答えます。

受けた後

  • 人についての記載や個人の情報について求めがあったときは、判断の前に、その記載をいまの版から外します。リポジトリの履歴に残る分も、できる限り消します。
  • 運営者は、7 日以内に答えることを目指します。
  • 直したことは、リポジトリの履歴に残ります。

言語モデル

このリポジトリは、運営者が言語モデル（Claude）の手を借りて手入れしています。
運営者のほかの人が開いた issue の題と本文は、書いた人がその issue の中で同意したときだけ、言語モデルに渡します。同意がなければ、運営者が自分で読みます。
コメントは、言語モデルに渡しません。
